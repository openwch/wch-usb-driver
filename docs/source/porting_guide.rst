移植指南
============================

本节介绍如何将本协议栈移植到已有工程中，主要包括复制源码、配置头文件路径、添加源文件、提供配置头和完成板级适配。

复制文件
--------------------

将以下目录复制到工程中：

.. list-table::

   * - 目录
     - 说明
   * - ``include/``
     - 对外头文件，包括 USB 协议定义、设备/主机驱动头文件和类驱动头文件
   * - ``src/``
     - 与硬件无关的驱动核心实现，包括 ``设备驱动``、 ``主机驱动`` 和 ``类驱动``
   * - ``port/``
     - USB 控制器移植层，``usbfs/`` 对应全速 IP，``usbhs/`` 对应高速 IP
   * - ``board/``
     - 板级支持包，取自 ``chips/<family>/board/``，与所用芯片系列对应

``board/`` 中的 ``board.c`` 负责 USB 时钟、实例和中断初始化，可按实际硬件裁剪或替换。

配置头文件路径
--------------------

将以下目录加入头文件搜索路径：

.. code-block:: makefile

   INCLUDES += \
       include \
       port/usbfs \
       port/usbhs \
       board

注意：

需添加 ``port/usbfs``、 ``port/usbhs`` 子目录；只使用其中一种 IP 时，添加对应目录即可。

添加源文件
--------------------

将以下 C 源文件加入编译：

.. code-block:: text

   # 核心实现
   src/usbd_driver_core.c        # 使用设备功能时添加
   src/usbh_driver_core.c        # 使用主机功能时添加
   src/class/*/*.c               # 使用类驱动时按需添加

   # 移植层（按芯片 USB IP 选择）
   port/usbfs/*.c                # 全速 USBFS
   port/usbhs/*.c                # 高速 USBHS

   # 板级支持包
   board/*.c

``board/`` 与原有工程存在同名的 ``system_*.c``、``*_it.c`` 时，保留一份即可。

添加配置文件
--------------------

应用还需提供 ``usb_config.h`` 以选择驱动和配置资源，详见 :doc:`configuration_file`。

验证
--------------------

- 工程可正常编译链接，无头文件缺失或重复定义；
- 设备模式下主机能完成枚举；
- 主机模式下能识别并操作插入的 USB 设备；
- 打开日志宏可观察驱动运行状态。
