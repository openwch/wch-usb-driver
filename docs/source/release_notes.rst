版本说明
============================

本节记录协议栈的版本变更。

v1.0.0（2026-10-20）
--------------------

首个发布版本。

新增
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 设备核心驱动：设备枚举、标准请求处理、事件回调与端点传输。
- 主机核心驱动：端口检测、设备枚举、挂起 / 恢复与传输调度。
- 设备类驱动：HID、CDC-ACM。
- 主机类驱动：HUB、HID（键盘 / 鼠标解析）、CDC-ACM。
- USBFS / USBHS 移植层，支持 ch32v205、ch32v30x、ch32v4x7 系列芯片。
- 设备、主机及双设备示例。
